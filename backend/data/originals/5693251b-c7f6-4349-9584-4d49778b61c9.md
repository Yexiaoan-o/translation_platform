## 新功能

### 基于 Session/Connection 的操作

支持 `sql` 方法。

### 数据形式和类型

支持多种数据形式和数据类型：

- 数据形式：标量、向量、数据对、矩阵、集合、字典、表。针对每种类型提供对应的构造及转换方法。
- 数据类型：逻辑、字面量、数值、时间、空值等多种类型。

### 函数

- **函数库**：提供种类丰富的函数，包含基础运算、统计与计算、窗口、聚合函数等。
- **自定义函数**：支持回调和翻译两种模式。
- 支持多种高阶函数，可接收其他函数作为参数，将函数对象与数据对象组合，以简洁的方式实现高效计算。
- 支持通过 `sf.parital` 固定函数的部分参数，简化函数调用。
- 支持元编程 `sf.meta_code`，将处理逻辑生成元代码对象，以便在不同时间或计算环境中动态解析执行。

### SQL 支持

支持与 DolphinDB 一致的 SQL 查询操作，包括 ANSI SQL-92 标准 SQL 语法和扩展 SQL 语法。能够在 Python 环境中充分利用 DolphinDB 的强大功能进行复杂的数据分析和处理。

### 插件

- 支持模拟撮合：可以模拟特定时间点的下单和取消订单操作，并生成相应的交易结果。
- 支持回测：提供完整的回测框架，支持股票、期货、期权、债券及加密货币等多种资产的策略回测。

### 存储引擎与数据库支持

支持创建内存表和分布式表，支持多种存储引擎：OLAP、TSDB、PKEY、OLTP。

### 流数据处理能力

- 支持多种类型流数据表。
- 支持流数据订阅与发布。
- 支持多种流计算引擎。

### 输入输出

- 支持将数据序列化并存储为文件或序列化为二进制内容。
- 支持从文件或二进制内容中反序列化为原始数据。
